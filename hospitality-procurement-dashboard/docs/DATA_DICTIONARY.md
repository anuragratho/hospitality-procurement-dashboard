# Data Dictionary

All tables are generated by `src/generate_data.py` (raw) and `src/analysis.py` (processed). Money is in euro. Dates are ISO `YYYY-MM-DD`. Fiscal and contract years run October to September: FY25 / CY1 = Oct 2024 – Sep 2025, FY26 / CY2 = Oct 2025 – Sep 2026.

## Entity relationships

```
hotels ──┐
         ├──< purchase_orders >── suppliers
products ┘        │   (one row per PO line)
   │              ├── deliveries   (1:1, goods received)
   │              └── invoices     (1:1, supplier invoice line)
   ├──< contract_prices   (one per product per contract year)
   ├──< market_prices     (one per product per month)
   └──< stock_counts >── hotels   (bar products, monthly)
```

## Raw tables (`data/raw/`)

### hotels
| Column | Type | Description |
|---|---|---|
| hotel_id | text | Key, e.g. `H01` |
| hotel_name | text | Fictional property name |
| city | text | Location |
| rooms | int | Bedroom count, drives order volumes |
| compliance_discipline | 0–1 | Simulation lever: higher = less off-contract buying and shrinkage |

### suppliers
| Column | Type | Description |
|---|---|---|
| supplier_id | text | Key, e.g. `S01` |
| supplier_name | text | Fictional supplier |
| subcategories | text | Subcategories served, `;`-separated |
| is_contracted | bool | Has a group supply agreement |
| lead_time_days | int | Standard order-to-delivery days |
| delivery_reliability | 0–1 | Probability a delivery arrives on time |
| invoice_accuracy | 0–1 | Probability an invoice line has no keying error |
| price_creep_tendency | 0–1 | Average premium charged above contract (contracted suppliers) |
| payment_terms_days | int | 30 for contracted, 0 (cash) for spot suppliers |

### products
| Column | Type | Description |
|---|---|---|
| product_id | text | Key, e.g. `P001` |
| product_name | text | Item and pack size |
| category | text | Food, Beverage, Operating Supplies |
| subcategory | text | One of 15 subcategories |
| unit | text | Unit of purchase |
| base_price | € | Contract price in CY1 |
| base_weekly_qty_per_100_rooms | float | Demand driver before seasonality |
| preferred_supplier_id | text | Contracted supplier for the subcategory |

### contract_prices
| Column | Type | Description |
|---|---|---|
| product_id, supplier_id | text | Product and contracted supplier |
| contract_year | text | `CY1` or `CY2` |
| valid_from, valid_to | date | Validity window |
| contract_price | € | Agreed unit price |

### market_prices
| Column | Type | Description |
|---|---|---|
| product_id | text | Product |
| month | `YYYY-MM` | Month |
| market_price | € | Open-market price: category inflation plus a random walk |

### purchase_orders
| Column | Type | Description |
|---|---|---|
| po_line_id | text | Key, `PO100123-04` |
| po_number | text | PO header: one per hotel, supplier and order date |
| hotel_id, supplier_id, product_id | text | Foreign keys |
| order_date | date | Order placed (Mondays and Thursdays) |
| expected_delivery_date | date | Order date + supplier lead time |
| contract_year | text | `CY1` / `CY2` |
| on_contract | bool | Ordered from the contracted supplier at contract price |
| buyer | text | Role that raised the order |
| qty_ordered | int | Units ordered |
| po_unit_price | € | Price on the PO (contract price, or the spot quote if off-contract) |
| contract_unit_price | € | Group contract price for benchmarking |
| po_line_value | € | qty_ordered × po_unit_price |

### deliveries
| Column | Type | Description |
|---|---|---|
| grn_number | text | Goods received note, one per PO |
| po_line_id, po_number | text | Links to the PO line |
| delivery_date | date | Actual delivery date |
| qty_received | int | Units received (can be short) |

### invoices
| Column | Type | Description |
|---|---|---|
| invoice_number | text | One per PO |
| po_line_id, po_number, supplier_id | text | Links |
| invoice_date | date | Delivery date + 0–5 days |
| qty_invoiced | int | Usually qty received; some suppliers bill qty ordered |
| invoice_unit_price | € | Price charged (may include creep or keying errors) |
| invoice_line_value | € | qty_invoiced × invoice_unit_price |

### stock_counts (beer, wine and spirits only)
| Column | Type | Description |
|---|---|---|
| hotel_id, product_id | text | Keys |
| month | `YYYY-MM` | Count month |
| opening_qty | int | Previous month's counted closing stock |
| received_qty | int | Units delivered in the month |
| sold_qty_pos | int | Units sold per the till (POS) |
| theoretical_closing_qty | int | opening + received − sold |
| counted_closing_qty | int | Physical count |
| variance_qty | int | counted − theoretical (negative = loss) |
| unit_cost | € | Average purchase cost |
| variance_value | € | variance_qty × unit_cost |

## Processed tables (`data/processed/`)

| File | Grain | Key measures |
|---|---|---|
| kpi_summary.csv | KPI × FY25 / FY26 / Total | Headline KPIs and FY26 − FY25 change |
| monthly_trend.csv | month | spend, on/off-contract spend, PPV, OTIF %, match %, contract price drift % |
| spend_by_category.csv | category × subcategory | spend, share, on-contract %, PPV |
| hotel_summary.csv | hotel | spend, spend per room, on-contract %, OTIF, match %, shrinkage |
| supplier_scorecard.csv | supplier | OTIF, on-time, in-full, invoice accuracy, price gap, score, rating |
| supplier_pareto.csv | supplier | cumulative share of spend |
| price_variance.csv | product × contract year | contract vs average paid price, variance % and € |
| off_contract.csv | hotel × subcategory × supplier | off-contract spend, premium paid |
| invoice_exceptions.csv | invoice line | exception type, expected vs invoiced value, discrepancy |
| stock_variance.csv | hotel × drinks subcategory | units sold, variance, shrinkage % |

## Derived fields in the fact table

| Field | Rule |
|---|---|
| fiscal_year | `FY` + (year + 1 if month ≥ October) |
| on_time | delivery_date ≤ expected_delivery_date |
| in_full | qty_received ≥ qty_ordered |
| otif | on_time and in_full |
| price_match | abs(invoice_unit_price − po_unit_price) ≤ €0.005 |
| qty_match | qty_invoiced = qty_received |
| three_way_match | price_match and qty_match |
| expected_invoice_value | qty_received × po_unit_price |
| invoice_discrepancy | invoice_line_value − expected_invoice_value |
| ppv_value | (invoice_unit_price − contract_unit_price) × qty_invoiced |
| benchmark_value | contract_unit_price × qty_invoiced |
